# PyGastos

Aplicación de consola desarrollada en Python para registrar
gastos personales y calcular el total gastado.

## Funcionalidades

- Registrar gastos con descripción y monto.
- Mostrar todos los gastos registrados.
- Calcular el total de gastos.
- Guardar los datos localmente en formato JSON.

## Tecnologías

- Python 3
- Git
- GitHub
- JSON

## Requisitos

Tener Python 3 instalado.

## Cómo ejecutar el proyecto

1. Clona este repositorio.
2. Abre una terminal dentro de la carpeta del proyecto.
3. Ejecuta:

   ```
   python main.py
   ```

   En macOS o Linux también puedes usar `python3 main.py`.
